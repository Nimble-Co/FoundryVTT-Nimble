# The New Sheets (Preview)

The new character sheet is a preview. It is in the system beside the old character sheet, and the old sheet stays the default. Try the new sheet, and tell us what you find. When the test period is over, the new sheet becomes the default.

## The new character sheet

The new character sheet has a rail with your Hit Points, mana, wounds and Hit Dice, and eight tabs: Core, Actions, Features, Inventory, Spells, Effects, Bio and Settings. A click on a row uses the thing. The arrow at the start of a row shows its full text. The pen at the end opens its window. Turn on edit mode to configure the values of your character and to delete items.

## Use the new sheet for one character

1. Open the character sheet.
2. In the window header, open the menu and click **Configure Sheet**.
3. In **This Sheet**, select **Character sheet (Hero)**.
4. Click **Save**. The character opens in the new sheet.

To go back, do the same steps and select **Nimble Player Character Sheet**.

## Make the new sheet the default for all characters

Only a GM can do this.

1. Open the sheet of a character.
2. In the window header, open the menu and click **Configure Sheet**.
3. In **Default Sheet**, select **Character sheet (Hero)**.
4. Click **Save**. All characters that have no sheet set by hand now open in the new sheet.
