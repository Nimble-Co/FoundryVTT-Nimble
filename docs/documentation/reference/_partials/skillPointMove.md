**Example: Jack of All Trades.** The Songweaver's level 2 feature reads "When you Safe Rest, you may move a skill point as if you just leveled up."

- **Label** → `When you Safe Rest`
- **Points** → `1`
- **Offered on** → `Safe Rest`

The safe rest window now offers to move one skill point. A move is net zero: a point can only be added to one skill by taking it from another, so the character's total never changes. The two limits the rulebook states are enforced, so a skill cannot be taken below zero and cannot be raised above +12.

Unlike a level-up, a move is not recorded against a level. It changes the skill totals directly, which is what keeps it from being undone the next time the character levels down.

Several rules on one character add up, so a character with two such features may move two points.
