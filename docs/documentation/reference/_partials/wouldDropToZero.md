**Example: Ha! I'm Over Here!** An attack that would drop you to 0 HP moves you instead, and you take no damage. The Wound that drop would cause does not land.

- **Instead** → Take no damage
- **Who decides** → Apply it
- **Move** → the distance

**Example: stay up.** Leave the creature at 1 HP, and optionally gain a different number of Wounds. That gain is not the Wound the drop would have caused.
