**Example: Ha! I'm Over Here!** An attack that would drop you to 0 HP is prevented, once per Safe Rest, and you may move up to your speed away from the attacker. Declining the move still prevents the damage. The Wound that drop would cause does not land.

- **Instead** → Take no damage
- **Who decides** → Apply it
- **Who** → This creature
- **Move** → `@speed`
- **Direction** → Away from the attacker
- **Attacks only** → on
- **Charge pool** → the Safe Rest pool

**Example: stay up.** Leave the creature at 1 HP, and optionally gain a different number of Wounds. That gain is not the Wound the drop would have caused.
