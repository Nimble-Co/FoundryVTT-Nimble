**Example: Shadow Trap, upcast.** "+1d12 damage when they escape" for each upcast step.

- On the **Rules** tab of the spell's effect (Restrained, with its Escape), this rule with **Damage** left blank
- On the spell's upcast, a **Raise Effect Rule** on **Damage**, with `1d12` for each step

At the base tier, the rule deals no damage. Cast two tiers up, the copy on each target has `1d12 + 1d12`. When a target escapes, the active GM's client rolls and deals the damage. The roll card of the escape gets the line, with **Undo**.
