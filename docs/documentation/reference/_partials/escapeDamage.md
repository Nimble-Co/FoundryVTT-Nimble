**Example: Shadow Trap, upcast.** "+1d12 damage when they escape" for each upcast step.

- On the spell's effect (Restrained, with its Escape), the **Rules** tab: this rule with **Damage** left blank
- On the spell's upcast: **Raise Effect Rule** on **Damage**, with `1d12` for each step

At the base tier the rule deals nothing. Cast two tiers up, the copy on each target has `1d12 + 1d12`. When a target escapes, the active GM rolls it and deals it, and the roll card of the escape gets the line with **Undo**.
