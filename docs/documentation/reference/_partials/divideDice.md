**Example: Grim Harrow.** The Reaver divides the dice of the Bonescythe among the targets.

- **Only attacks made through** → `bonescythe`

The Bonescythe's DEX necrotic damage has **Divides With the Dice** on, so each target takes the DEX of its own dice. Target 2 or more creatures and use the Bonescythe: the roll window shows a row for each target.
