The Chaos Options rule changes each roll on the Chaos Table of its owner. **Roll twice** shows three buttons on the card before the roll: roll once, roll twice and both happen, or roll twice and choose one. **Pool to choose one** is the use the last button spends. **Advantage** gives each roll advantage.

**Example: Thrive in Chaos.** Roll twice, choose one, 1/Safe Rest.

- **Roll twice** → on
- **Pool to choose one** → `thrive`
