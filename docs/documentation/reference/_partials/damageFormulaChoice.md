**Example: Versatile Bowmaster.** On a longbow attack, a tick in the roll window lets the player roll 2d4 instead of 1d8.

- **Item identifier** → `longbow`
- **Instead of** → `1d8`
- **Roll** → `2d4`

The tick starts off. With the tick off, or when the roll window is skipped, the attack rolls the weapon's own damage. A crossbow uses a second rule, `4d4` to `2d8`.
