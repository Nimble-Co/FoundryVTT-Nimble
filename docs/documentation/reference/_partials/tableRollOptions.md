The Table Roll Options rule changes each roll of its owner on its **Table**, the Chaos Table now. **Roll twice** shows three buttons on the card before the roll: roll once, roll twice and both happen, or roll twice and choose one. **Pool to choose one** is the use the last button spends. **Advantage** gives each roll advantage.

**Example: Thrive in Chaos.** Roll twice, choose one, 1/Safe Rest.

- **Table** → Chaos Table
- **Roll twice** → on
- **Pool to choose one** → `thrive`
